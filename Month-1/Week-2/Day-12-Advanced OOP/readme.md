# Day 12 – Advanced Object-Oriented Programming (OOP)

## Overview

Day 12 focused on Advanced Object-Oriented Programming (OOP), one of the most important concepts in software development. I learned how to build more organized, reusable, and scalable applications using inheritance, encapsulation, polymorphism, and abstraction. These concepts are widely used in modern Python frameworks and AI libraries such as PyTorch, FastAPI, and scikit-learn.

To reinforce these concepts, I built a **Library Management System** using multiple classes and OOP principles.


## Learning Objectives

- Understand inheritance and method overriding.
- Learn how to use `super()` to access parent class methods.
- Understand encapsulation and data protection.
- Learn polymorphism and abstraction.
- Work with class variables, class methods, and static methods.
- Apply advanced OOP concepts by building a complete project.


##  Topics Covered

### Inheritance
- Creating parent and child classes
- Reusing code through inheritance
- Method overriding

### Encapsulation
- Protected attributes (`_variable`)
- Private attributes (`__variable`)
- Data hiding

### Polymorphism
- Using the same method name with different implementations
- Method overriding in child classes

### Abstraction
- Abstract classes
- Abstract methods
- The `abc` module

### Other OOP Features
- Class variables
- Class methods (`@classmethod`)
- Static methods (`@staticmethod`)
- Properties (`@property`)

##  AI Engineering Connection

Advanced OOP is fundamental to AI engineering.

Many popular AI frameworks rely heavily on inheritance and object-oriented design:

- **PyTorch** models inherit from `torch.nn.Module`.
- **Scikit-learn** models share methods like `fit()` and `predict()`.
- **FastAPI** uses classes to define request and response models.
- **LangChain** components inherit from common base classes, making them interchangeable.

Understanding OOP makes these frameworks much easier to learn and use.
